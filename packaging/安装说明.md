# ChatGPT Manager 安装与首次配置

安装器会先显示本次运行的安装包路径、安装目标以及将创建的三个目录。全新安装默认使用 `C:\ChatGPT Manager`；检测到旧版时继续使用原目录以保证兼容。确认路径无误后继续；ChatGPT 正在运行时安装会被阻止。

安装后会创建或补齐以下目录：

- `C:\ChatGPT Manager\APP`：程序和说明文档
- `C:\ChatGPT Manager\Official`：官方配置来源
- `C:\ChatGPT Manager\Transit`：个人中转配置来源

安装包只包含 APP 程序和两个配置目录的放置说明，不包含制作此安装包的电脑上的 `config.toml`、`auth.json` 或安全备份。

首次使用按此顺序操作：

1. 启动 `APP\ChatGPTManager.exe`，在中转卡片输入 API 密钥并点“保存密钥”。
2. 完全退出 ChatGPT，点击“切换到中转”。程序自动定位 `CODEX_HOME`，或当前用户的 `%USERPROFILE%\.codex`，并只操作其中的 `config.toml` 与 `auth.json`。
3. 首次切换时，若 Official 为空，程序会先原样保存当前文件对；然后应用 Transit 配置。收到成功提示后再打开 ChatGPT。

安装包不会携带制作者电脑上的配置、令牌或 API 密钥。需要更换密钥时，在 ChatGPT 完全退出后输入新密钥并点“替换密钥”。

ChatGPT 运行时不能保存密钥或切换配置。若已保存密钥且当前配置正在使用中转，卸载会提示并阻止删除；先切回官方即可卸载。密钥已保存但当前未使用中转时，允许卸载。通过卸载检查后，程序会恢复 Official 或安全副本中的完整配置；没有可恢复配置时保留当前 `.codex` 文件。
